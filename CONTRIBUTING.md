# Contributing to kubus-node

Thanks for your interest in contributing.

## Before you start

- Check existing issues/PRs before opening a new one.
- Keep changes small and focused.
- Run the relevant test/lint/build commands from `package.json` locally before opening a PR.

## Questions

For general help, open a discussion or issue. For security issues, follow the project's security reporting process if one is documented, or contact support@kubus.site.
